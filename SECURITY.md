# Security policy

Breach Escape is a static, client-side game with no backend, no accounts and no data collection.

## Reporting a vulnerability

Please report security issues privately, not in public issues:

- Use GitHub's **"Report a vulnerability"** button on the Security tab of this repository, or
- email **admin@keptacademy.com**.

Include steps to reproduce and the affected URL or file. You'll get a reply within 7 days.

## Scope

In scope: the game at play.keptacademy.com and the code in this repository (including the security headers in `staticwebapp.config.json`).

Out of scope: the breach scenarios themselves. They describe real, already-public incidents for teaching.
